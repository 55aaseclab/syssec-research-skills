# syssec-figures

Use `syssec-figures` to align visuals with claims and evidence.

## Inputs

- claim-evidence map
- results summary
- system notes

## Outputs

- figures plan
- table plan
- caption guidance

## Workflow

1. Map each key claim to the visual that proves it best.
2. Separate architecture, method, and evaluation visuals.
3. Remove visuals that do not support a real point.
4. Mark missing captions, units, labels, or caveats.
5. Route finalized visual requirements to writing or submission.

## Boundaries

- A beautiful plot cannot fix weak evidence.
- Avoid visuals that imply more generality than the data supports.
