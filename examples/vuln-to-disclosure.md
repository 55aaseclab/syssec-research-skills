# Example: Vulnerability To Disclosure

- User state: "We may have a privilege-escalation issue in this daemon."
- First route: `syssec-investigation`
- First deliverables:
  `system-notes.md`, `attack-surface-map.md`, `findings-log.md`
- Likely next path:
  static or dynamic analysis → exploit validation → evaluation → disclosure →
  writing → post-submission
