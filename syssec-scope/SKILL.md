# syssec-scope

Use `syssec-scope` to turn an area of interest into a defensible research
problem.

## Inputs

- research brief
- target system class
- intended workflow
- current evidence state

## Outputs

- `questions-and-hypotheses.md`
- `threat-model.md`
- success criteria
- explicit non-goals

## Workflow

1. State the target assets and adversary.
2. State the attack or defense surface in scope.
3. Record assumptions and trust boundaries.
4. Define hypotheses or evaluation questions.
5. Define what would count as success or failure.

## Boundaries

- Do not let the threat model stay implicit.
- Route back to intake if the main deliverable is still unclear.
