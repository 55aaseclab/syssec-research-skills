# syssec-submission

Use `syssec-submission` to turn a draft into a defensible submission package.

## Inputs

- paper draft
- claim-evidence map
- figure and artifact status
- venue requirements

## Outputs

- `submission-checklist.md`
- blocker list
- ready or not-ready status

## Workflow

1. Check venue formatting and required sections.
2. Check evidence support for all headline claims.
3. Check artifact, appendix, and ethics completeness.
4. Check disclosure-sensitive content one more time.
5. Route unresolved blockers back to the owning stage.

## Boundaries

- Deadline pressure is not a reason to hide missing evidence.
- Submission readiness is a technical state, not a mood.
