# Submission Checklist

## Manuscript

- [ ] Main claims match the claim-evidence map.
- [ ] Threat model is explicit.
- [ ] Evaluation limits are stated.
- [ ] Related work covers close neighbors.

## Figures And Tables

- [ ] Every key figure supports a claim.
- [ ] Units, labels, and captions are complete.

## Artifact And Reproducibility

- [ ] Setup path exists.
- [ ] Run path exists.
- [ ] Expected outputs are documented.

## Ethics And Disclosure

- [ ] Sensitive detail is reviewed.
- [ ] Disclosure status is reflected correctly.

## Venue Compliance

- [ ] Formatting rules checked.
- [ ] Required metadata or appendices included.
