# Stage Router

Use this note when the current request spans multiple lifecycle stages.

## Router questions

1. What stage is the user actually blocked on now?
2. What artifact should exist before the next stage can work honestly?
3. What evidence class supports the current answer?
4. Is the next move planning, implementation, evaluation, or writing?

## Fast routing hints

- vague direction → `syssec-foundation`
- technical system analysis → `syssec-investigation`
- proof, replay, or benchmarking → `syssec-validation`
- paper, disclosure, or review response → `syssec-publication`
